# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records that document important architectural decisions made during the development of the Skilled Worker Hiring Platform.

## Format

Each ADR should include:
- Title
- Status (Proposed, Accepted, Deprecated, Superseded)
- Context
- Decision
- Consequences

## Naming Convention

ADRs should be named using the pattern: `YYYYMMDD-descriptive-title.md`
